Method

How the Observatory Decides What It Knows

Every number on this site answers three questions: who measured it, when did the ledger learn it, and what would prove it wrong.

Two clocks

Each entry carries recorded_on — transaction time, when the entry entered the ledger — and domain dates for when the fact is true in the world. An as-of query means recorded_on ≤ T. The hindcast view is computed from that rule, and a leakage test proves a 2024 snapshot cites only facts that were public in 2024.

Prohibited transforms

The following transitions require separate evidence each time — never inferred from the previous rung: funded → validated; selected → proven; qubits → useful scale; benchmark win → general advantage; quantum advantage → economic advantage; system delivered → customer value; roadmap → forecast fact; funding → technical progress; patent → working tech; partnership → revenue.

Confidence decomposition

There is no headline score. Each case-study subject carries a four-axis range — technical architecture, execution, market utility, value capture — and NOT YET ESTIMABLE is a valid answer, displayed as an empty track rather than a thin fake bar.

Fail closed

scripts/check_observatory.py enforces the schema, citation resolution, independence rules, milestone evidence requirements, forecast resolution hygiene, and temporal-leakage limits. Any violation stops the build before output is written. UNKNOWN is acceptable; fabricated precision is not.
